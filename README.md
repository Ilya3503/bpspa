# BPSPA

Система компьютерного зрения для определения положения объектов в пространстве по облакам точек с камеры RealSense.

---

## Запуск и управление

Приложение работает как systemd-сервис. Все команды запускаются **из корня проекта**, venv активировать не нужно — `make` делает это сам.

```bash
make start     # запустить сервис в фоне (терминал не блокируется, логов не видно)
make stop      # остановить сервис
make restart   # перезапустить
make status    # состояние сервиса
make check     # быстрая проверка: отвечает сервис или нет
make run       # запустить с логами в терминале (терминал блокируется, Ctrl+C для выхода)
make help      # список всех команд
```

## Логи

```bash
make logs      # живой хвост логов (Ctrl+C для выхода)
```

## Push и пайплайн

Креды git уже настроены — логин/токен вводить не нужно.

При любом push в `main` устройство **само** делает git pull, перезапускает сервис и проверяет, что он живой. Ручной git pull на устройстве больше не нужен.

Статус пайплайна — в репозитории на GitHub, вкладка **Actions**. Зелёная галочка = всё прошло.

Ссылка: https://github.com/Ilya3503/bpspa/actions

## Работа с ветками (git flow)

Можно коммить напрямую в `main`, но лучше сначала поработать на отдельной ветке.

```bash
git checkout main
git pull                          # подтянуть свежий main
git checkout -b <название новой ветки>

git push -u origin <название новой ветки>
```

Дальше на GitHub открой **Pull Request** из своей ветки в `main`. На каждый PR автоматически прогоняется проверка — дождись **зелёной галочки** во вкладке Actions, она означает, что мержить безопасно. После мержа в `main` сработает автоматическое развертывание на устройство.
